# Eigene Grafik

Dateien hier werden automatisch benutzt, sobald sie existieren. Der Dateiname ist der Kartenname
in Kleinbuchstaben, alles außer Buchstaben und Ziffern wird zu `_`:

- `cards/swap_frog.png`: Kartenbild für „Swap Frog“ (liegt auf der Karte, Seitenverhältnis 59:86).
- `models/swap_frog.glb`: 3D-Figur für „Swap Frog“ (steht auf der Karte, Füße im Ursprung, etwa 1,5 bis 2,5 hoch).
- `models/duelist.glb`: Figur für beide Duellanten.

Nur eigene oder frei lizenzierte Grafik verwenden. Kartenbilder und Figuren von Konami sind geschützt.
